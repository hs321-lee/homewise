# Homewise

월세는 사라지고, 집은 남는다.

무주택 직장인이 **사내 저리 대출 · 은행 주담대 · 월세**를 같은 기준으로 비교하는 상담용 계산기입니다. 브라우저에서 숫자를 바꾸면 바로 다시 계산합니다.

## 무엇을 보여주나

- **추천 경로**: 자금이 모자라지 않고 감당할 수 있는 경로 중 10년 누적 비용이 가장 적은 것
- **시중의 돈은 계속 늘어난다**: 통화량(M2) 증가율과 10년 순자산 비교 (월세 + 예금 vs 집)
- **무엇을 살까**: 수원 매탄·망포 생활권 대장 단지 시세와 자금 가능 여부
- 구간별 매달 나가는 돈, 10년 누적 비용, 흔히 듣는 말 팩트 체크, 살 수 있는 최고가, 조건 체크

## 계산 기준

- 사내 대출: 본인 부담 금리와 세법상 인정 금리의 차이를 근로소득에 더해 세금 계산
- 은행 주담대: min(한도, 집값 × LTV, DSR 40%), 30년. 장기주택저당차입금 이자 소득공제(공시가 6억 이하, 5년 주기형 1,800만 / 원금균등 2,000만 / 혼합형 800만)
- 세금, 취득세, 재산세는 단순화한 추정입니다. 자세한 가정은 페이지 아래 "계산 가정"에 있습니다.

참고용 계산기이며 투자·세무·대출 자문이 아닙니다.

## 개발

```bash
npm test          # 계산 로직 테스트 (Node 22, 외부 의존성 없음)
```

- `site/index.html`: 화면
- `site/calc.js`: 계산 로직 (브라우저 `window.Homewise`, Node `require` 둘 다 지원)
- `test/calc.test.js`: 테스트

`main`에 push하면 GitHub Actions가 테스트 후 GitHub Pages로 배포합니다. 처음 한 번은 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꿔야 합니다.
